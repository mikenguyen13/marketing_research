# Scientific Writing

+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Section           | Length (words) | Purpose                                              | Verb Tense                                         | Elements                           |
+===================+================+======================================================+====================================================+====================================+
| Title             | 8 - 15         |                                                      |                                                    |                                    |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Abstract          | 200-250        | Paper's summary                                      | Simple past (work done)                            | -   Objectives                     |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      | Present (general fact, paper itself or analysis)   | -   Methods                        |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      |                                                    | -   Results                        |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      |                                                    | -   Conclusions                    |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Introduction      | 500-1000       | Rationale for the paper                              | Present (current state-of-art, general background) | -   The problem                    |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      | Present perfect (previous research)                |                                    |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Literature Review | 1000-2000      | Understanding of the current knowledge landscape     | Present (current state-of-art)                     | -   Review of the literature       |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      |                                                    | -   Hypothesis                     |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Methods           | 500-1000       | What was done                                        | Simple past (work done)                            | -   Approach/ methods used         |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      | Present (explain diagrams/figures)                 | -   Data description               |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      |                                                    | -   Procedure description          |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Results           | 500-1500       | presents data, facts                                 | Simple past (what was found)                       | -   Results of analysis            |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      | present (explain diagrams/figures)                 |                                    |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+
| Discussion        | 1000-1500      | discuss relationships among constructs, and insights | Present (established knowledge)                    | -   Relationships                  |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      | past (summarize findings)                          | -   Outliers                       |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      |                                                    | -   Comparison to previous studies |

| Conclusions       | 500            | summarize findings                                   | Present (implications and future search)           |                                    |
|                   |                |                                                      |                                                    |                                    |
|                   |                |                                                      | Past (completed research)                          |                                    |
+-------------------+----------------+------------------------------------------------------+----------------------------------------------------+------------------------------------+

Rules of thumb:

-   Past: events that have been completed

    -   We found

    -   Method proposed by X was followed

-   Present Perfect: events that started in the past but are still ongoing

    -   Many studied have researched on

-   Present: events that are general fact, and current

<br>

Journal paper types:

1.  Research Paper: hypotheses and findings
2.  Methods Paper: new method
3.  Review Paper: consolidate a domain
4.  Discussion Paper: opinions regarding other papers
